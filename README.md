## Descripción del repositorio

Este repositorio permite organizar, gestionar y realizar el seguimiento de los entregables correspondientes a las tres unidades del curso. Su estructura facilita la documentación técnica, el control de versiones, la trazabilidad de los avances y la presentación de evidencias del proyecto.

Los cambios relacionados con el código se registrarán mediante commits, ramas y Pull Requests cuando corresponda.

## Organización

### Unidad 01 - Revisión y planificación del software

La primera unidad contiene la estructura inicial de trabajo:

- Revisión de código.
- Especificaciones funcionales.
- Casos y catálogo de pruebas.
- Planes de iteración.
- Laboratorios y evidencias.
- Código fuente.
- Actas de reunión.

Consulta la estructura completa en [UNIDAD_01](UNIDAD_01/README.md).

### Unidad 02 - Desarrollo progresivo

Espacio destinado a los documentos técnicos, actividades, laboratorios, código y evidencias que se incorporen durante el desarrollo de la segunda unidad.

Consulta [UNIDAD_02](UNIDAD_02/README.md).

### Unidad 03 - Desarrollo progresivo

Espacio destinado a los entregables, pruebas, laboratorios y evidencias correspondientes a la tercera unidad, que se agregarán conforme avance el curso.

Consulta [UNIDAD_03](UNIDAD_03/README.md).
