# Unidad 02 - Desarrollo progresivo

Documentos, actividades, código y evidencias correspondientes a la segunda unidad del proyecto DocuZen.

## Organización

- `01_REVISION_CODIGO`: estándares, revisión y gestión de configuración.
- `02_ESPECIFICACIONES_FUNCIONALES`: formatos y documentos técnicos del proyecto.
- `03_CASOS_DE_PRUEBA`: casos, catálogo e informes de pruebas.
- `04_PLANES_ITERACION`: planificación, despliegue, riesgos y cronograma.
- `05_LABORATORIOS`: evidencias de GitHub, informes y bitácora de avance.
- `06_CODIGO_FUENTE`: aplicaciones, documentación y pruebas del código fuente.
- `07_ACTAS_REUNION`: actas de las reuniones de la unidad.
